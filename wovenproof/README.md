# 织纹校对 · 多综织机组织图本地校对工具

供多综织机手织者校对组织图的**纯本地 Web 工具**。仅依赖 Python 标准库
（`http.server` + `sqlite3`），前端为原生 HTML / CSS / JavaScript / SVG，
**无任何外部网络资源，断网可用**。

## 运行

```bash
cd wovenproof
python3 server.py
```

浏览器打开 <http://127.0.0.1:8765/> 即可。停止按 `Ctrl+C`。

- 所有数据只存在本机：项目/版本在 `wovenproof.db`（SQLite），工作草稿在浏览器 `localStorage`。
- 端口固定 8765；如被占用，改 `server.py` 末尾的 `PORT`。

## 功能

### 编辑（穿综 / 踏板连结 / 踏序，或直提升综计划）
- 设置综框、踏板、经纱、纬纱数量，选择**提综**或**沉综**开口逻辑。
- 编辑区可在**踏板组织图**与**直提升综 LIFTPLAN**两种模式间切换：
  - 踏板模式：连结 + 踏序两个网格；直提模式：升综计划按「纬次×综框」排网格，
    点涂/拖涂每纬升起的综框（遵循 WIF LIFTPLAN 约定，标记=升起，与开口逻辑无关）。
- 三个输入网格支持点按、按住拖涂、右键临时擦除；工具模式：点涂 / 擦除 / 切换 / 选区。
- **选区**：拖出矩形后可复制、剪切、把选区图案循环扩展到网格末端；
  复制后切到点涂，单击任意网格位置即可粘贴。
- **撤销 / 重做**（Ctrl+Z / Ctrl+Y），成布组织图随编辑即时重算；模式切换也入栈。
- 穿综约束为每根经纱只穿一片综（点新综自动移综）。

### 踏板 ⇄ 直提互转
- 从踏板模式切到直提：按现有连结与踏序逐纬生成 LIFTPLAN（沉综稿取“未连结而升起”的综框），
  漏踩踏板的纬记为漏织哨兵；原踏板稿保留在数据中，可撤销。
- 直提模式下设置条的“踏板”变为**踏板预算**，仍可直接调整。
- 从直提切回踏板：进行**复合踏板求解**，把每纬目标开口换算为若干踏板连结的并集
  （提综逻辑下＝升综综框，沉综逻辑下＝未升起而沉下的综框），两种开口逻辑下都与直提稿成布一致。
  - 切回前可设置**踏板预算**、**每纬最多同时踩下的踏板数**，并可勾选**把已有连结列锁为固定条件**
    （求解器保留这些列原位不动，只能在其后增补新列；固定列本身超预算时直接判无解）。
  - 候选按**踏板数 → 最大同时踩踏数 → 相邻纬换脚次数**排序，弹窗内并排预览
    **新连结、复合踏序、成布差异（红绿对比）与逐纬脚法**（每纬所踩踏板号、与上一纬的换脚数）。
  - 预算/同踩限制内无解时，列出**无法还原的纬次与目标开口**，直提稿保持不变；可一键放宽预算重解。
  - 候选可**放入沙盒手调**：点击连结/踏序格点任意修改，任何造成**目标开口**变化的格点立即红框标出
    （即使该综未穿经纱、成布上看不出来也一样拦截），同踩数超过上限的纬另以琥珀角标提示，
    状态条实时显示开口一致与否、最大同踩、成布差异与换脚次数；
    **只有每一纬目标开口完全一致、且最大同踩数不超过设定时才能采用**（采用前还会二次校验）。
  - 采用后进入踏板模式并接入既有撤销/重做、草稿、版本、逐纬播放、WIF 导出与打印图；
    全部纬均漏织（0 个有效开口）时不能求解。
- **全沉纬**：升综计划中某纬什么都不标（对应 WIF 的 `pick=0`）是有效开口，整纬纬纱在上，
  问题列表以蓝色提示标出；播放时该行虚线描边。只有从踏板稿带过来的漏织哨兵才标红记无交织。
  归并踏板时全沉纬对应一个“空连结踏板”。

### 逐纬播放
- ▶ 逐纬织造：同步高亮当前纬在踏序/升综计划中的格、被踩踏板或升起综框、综框尺，
  成布上高亮当前纬并显示织口生长线；可调速、单步、循环。

### 校对（问题列表与网格双向定位）
- 规则：正面（经向）/反面（纬向）最大浮长、最外侧 N 根边经必须逐纬交织。
- 检出：超长浮线、漏穿经纱、漏织纬、边经漏交织、未使用综框/踏板、
  死综、空连结踏板、缩小尺寸后的越界引用（可一键清除）。
- 问题在输入格、成布格、四把标尺上同步标色；点问题项滚动并闪烁定位，
  点成布问题格 / 标尺号反向高亮问题项，悬停有气泡说明。

### 变体
- 左右镜像（穿综反转）、上下反转（踏序倒序）、换面（提综⇄沉综）。
- 先生成当前/变体双预览，红绿标出差异，确认后才替换（进入撤销栈）。

### 存档 / WIF / 打印
- 一个项目可保存多个版本，随时载入或删除；删除项目级联清理其版本。
- 导入/导出 WIF（THREADING / TIEUP / TREADLING / LIFTPLAN、WARP/WEFT 颜色、Shed）。
  导入含 LIFTPLAN 的 WIF 时**原样保留升综计划**并进入直提模式；导出按当前编辑区模式
  写入 LIFTPLAN 或 TIEUP/TREADLING。模式切换与转换结果都进入撤销栈和版本草稿。
- 浏览器打印图：穿综 / 连结 / 踏序（或升综计划）/ 成布，带色纱、格号与红虚线重复边界
  （自动探测穿综与踏序/升综周期）。
- 内置可编辑示例：平纹、2/2 与 3/1 斜纹、五枚缎、山形斜纹。

## 文件

```
wovenproof/
├── server.py            # 标准库 HTTP 服务 + SQLite 存档 API
├── wovenproof.db        # 首次运行自动创建
└── static/
    ├── index.html       # 页面结构
    ├── app.css          # 样式（含打印样式）
    └── app.js           # 全部前端逻辑与 SVG 渲染
```

## API 摘要

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/projects` | 项目列表（含版本数） |
| POST | `/api/projects` | 按名称保存项目并新增一个版本 |
| GET | `/api/projects/<pid>` | 项目及其版本元数据 |
| DELETE | `/api/projects/<pid>` | 删除项目（级联删除其全部版本） |
| GET | `/api/projects/versions/<vid>` | 读取单个版本草稿 |
| POST | `/api/projects/<pid>/versions` | 给指定项目追加版本 |
| DELETE | `/api/projects/<pid>/versions/<vid>` | 仅当版本确属该项目时删除 |

所有错误均返回结构化 JSON：`{"ok": false, "error": "..."}`，
不存在的资源为 404，非法编号为 400。
