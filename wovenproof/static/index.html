    基本约定

    • 穿综：每列（一根经纱）点出它穿入的综框号。
    • 踏板连结：点出每个踏板连结哪些综框；同一踏板可连多片综。
    • 踏序：每行（一纬）点出所踩踏板；可一纬多踏板。
    • 提综逻辑：连结标记表示该综被提起，正面见经；沉综逻辑相反，正面见纬。
    • 成布最下一行为最先织的一纬（织口），向上生长。

    编辑区模式：踏板组织图 ⇄ 直提升综计划

    • 顶部可在踏板组织图（连结+踏序）与直提升综 LIFTPLAN（纬次×综框）间切换。
    • 升综计划里标记每纬升起的综框（与开口逻辑无关，遵循 WIF LIFTPLAN 约定）；未标综沉下，同样支持点涂/拖涂/擦除/选区与撤销重做。
    • 一纬什么都不标是有效的全沉纬（WIF 的 pick=0，整纬纬纱在上），问题列表会以提示标出；只有从踏板稿转换时遇到的漏织纬才记为无交织（红）。
    • 切到直提时按现有连结与踏序自动生成 LIFTPLAN（原踏板稿保留，可撤销）；沉综稿下列出的是未连结而升起的综框。
    • 切回踏板时进行复合踏板求解：把每纬目标开口换算为若干踏板连结的并集，提综/沉综逻辑下都保证成布与直提稿一致。
      • 可设置踏板预算（总片数）、每纬最多同时踩下的踏板数，并可勾选把已有连结列锁为固定条件（只能在其后增补新列）。
      • 候选按踏板数 → 最大同时踩踏数 → 相邻纬换脚次数排序；并排预览连结、复合踏序、成布差异、逐纬脚法。
      • 限制内无解时列出无法还原的纬次与目标开口，直提稿保持不变；放宽预算/同踩上限后可重解。
      • 候选可「放入沙盒手调」：点改连结/踏序后，任何造成目标开口变化的格点立即红框标出（即使该综没有穿经纱、成布看不出来也一样拦），同踩数超过上限的纬另以琥珀角标提示； 只有每一纬目标开口完全一致、且最大同踩数不超过设定时才能采用。

    操作

    • 在任一网格上可点按或按住拖涂；右键临时擦除。
    • 选区模式下拖出矩形，可复制、剪切、循环扩展到末端；复制后切换点涂，单击目标格粘贴。
    • Ctrl+Z / Ctrl+Y 撤销重做；Ctrl+D 取消选择。
    • 问题列表中的条目与三个输入格、成布格可互相点击定位。

    循环单元拼接校验

    • 「循环校验」页可查找周期（自动找出能完整复现当前穿综、踏序或 LIFTPLAN 的经纬周期），也可手动输入长度与起点后校验该单元。
    • 单元若不能平铺还原原稿，会逐格显示差异（红=原稿、绿=平铺），并不标为有效循环。
    • 有效单元给出 3×3 成布预演：粗框为中心单元，四边红虚线为接缝，边缘色条为色纱相位；浮长与边经交织按首尾相接（跨周期）计算，整行/整列跨周期连续会单独提示，点击问题可同时定位原稿两端。
    • 经向、纬向起点都可 ±1 旋转并即时对比接缝与颜色变化；预演穿综、踏序/升综计划与经纬色序的改动，确认「采用旋转结果」后写入原稿，并同步到撤销记录、本地草稿、版本、逐纬播放、WIF 与打印图。

    WIF

    支持导入/导出标准 WIF：THREADING/TIEUP/TREADLING 或 LIFTPLAN、WARP/WEFT COLORS、SHED。 导入含 LIFTPLAN 的 WIF 会原样保留升综计划并进入直提模式；导出按当前编辑区模式写入 LIFTPLAN 或 TIEUP/TREADLING。
